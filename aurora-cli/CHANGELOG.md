# Changelog

All notable changes to Aurora CLI will be documented in this file.

The project follows Semantic Versioning.

## [0.1.0] - 2026-08-03

### Added

- Aurora command registry and nested command tree
- Next.js project-template discovery and installation
- React component generators
- Transactional feature and package installation
- Package dependency scheduling and rollback
- Aurora Kernel lifecycle management
- Runtime plugin discovery and shutdown
- Structured Aurora errors with stable error codes
- Centralized CLI version metadata
- npm package-content validation
- Cross-platform continuous integration
- Installed-package release smoke testing

### Changed

- Consolidated project creation under one template engine
- Unified plugins under the runtime lifecycle
- Restricted npm package contents to production assets
- Standardized command failure exit codes

### Removed

- Obsolete service containers
- Legacy project-creation pipelines
- Experimental package-installation services
- Unused hardcoded CLI version module
